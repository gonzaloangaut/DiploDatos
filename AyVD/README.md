# Análisis y Visualización de Datos (Data Analysis and Visualization)

This folder contains all the projects completed during the course.  

- `Ejercicios` – all exercises completed in class.  
- `Entregables` – deliverable projects made by our group:  

1. **Entregable_Parte_1.ipynb** – used a survey from Sysarmy containing information about salaries of different programmers. We started with a descriptive analysis of the dataset and filtered out extreme cases. Then, we explored the most used programming languages and studied which ones offer higher salaries. We also analyzed whether knowing more than one language is advantageous. Finally, we explored relationships between different variables using various techniques.  

2. **Entregable_Parte_2.ipynb** – worked with the same dataset. We performed estimation and hypothesis tests to study differences in payments between men and women. Finally, we created a visualization (available in `Extras_Parte_2`) illustrating a meme based on insights obtained in the previous deliverable.
