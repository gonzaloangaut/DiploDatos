# Aprendizaje No Supervisado (Unsupervised Learning)

This folder contains all the projects completed during the course.  

- `Ejercicios` – all exercises completed in class.  
- `Entregables` – deliverable projects made by our group:  

**Entregable_ANS_Grupo_33.ipynb** – applied unsupervised learning to cluster football players using the FIFA 2025 dataset. We started by exploring the data and applying preprocessing. Then, we used K-Means and Hierarchical Clustering. Finally, we applied PCA followed by K-Means.
