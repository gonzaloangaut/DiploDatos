# Visión por Computadora (Computer Vision)

This folder contains all the projects completed during the course.  

1. **Lab_1_Intro_ANN.ipynb** – Implemented an Artificial Neural Network (ANN) for image classification using TensorFlow and the Fashion-MNIST dataset. Validated the model by creating and processing a custom dataset of real-world images to test generalization performance.

2.  **Lab_2_CNN_Grupo_4.ipynb** – Developed a Convolutional Neural Network (CNN) based on the LeNet architecture (convolution, pooling, and activation layers). We applied this model to various datasets and experimented with different architectural modifications to compare performance and identify optimal configurations.

3. **Lab_3_Transfer_Learning.ipynb** – Applied Transfer Learning techniques to leverage a pre-trained model on a new dataset. Specifically, we used MobileNetV2 (pre-trained on ImageNet) as the base network to perform a binary classification task (Cats vs. Dogs).
 
4. **Lab_4_Object_Detection.ipynb** – Focused on Object Detection and Instance Segmentation. We utilized the Mask R-CNN architecture to detect and segment objects within images.
 
5. **Lab_5_Semantic_and_Instance_Segmentation.ipynb** – Implemented a modified U-Net architecture to perform Semantic and Instance Segmentation tasks on image datasets.
