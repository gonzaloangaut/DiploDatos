# Introducción al Aprendizaje Automático (Introduction to Machine Learning)

This folder contains all the projects completed during the course.  

- `Ejercicios` – all exercises completed in class.  
- `Entregables` – deliverable projects made by our group:  

1. **Lab_1_grupo_33.ipynb** – used the "California Housing" dataset. We started with a description and visualization of the data. Then, we applied both linear and polynomial regression using multiple attributes. We also applied regularization using Ridge regression.  

2. **Lab_2_grupo_33.ipynb** – used the "Home Equity" dataset containing loan information. The target variable indicates whether an applicant fulfilled the loan payment. We predicted it using a linear model (`SGDClassifier`) and decision trees, comparing default hyperparameters with tuned ones.
