# Análisis Exploratorio y Curación de Datos (Exploratory Data Analysis and Curation)

This folder contains all the projects completed during the course.  

- `Ejercicios` – all exercises completed in class.  
- `Entregables` – deliverable projects made by our group:  

1. **EYCD_Entregable1_grupo33.ipynb** – used a dataset of property prices in Melbourne, Australia. We first built a SQLite database and used SQL to run queries. Then, we analyzed the data with Pandas: selected relevant variables, explored missing values, visualized distributions, removed outliers, and enriched the dataset with information from another source.  

2. **EYCD_Entregable2_grupo33.ipynb** – worked with the same dataset. We encoded categorical features, imputed missing data, and performed dimensionality reduction using PCA.
